<h1>AudioRoo Support</h1>

<h2>Common Questions</h2>

<h3>Which formats can I convert for free?</h3>
<p>MP3 conversion is free and unlimited, including batch processing and advanced settings. Every other format gets 15 free conversions, after which a one-time purchase unlocks all formats permanently. There is no subscription.</p>

<h3>I bought the unlock but it isn't showing</h3>
<p>Open AudioRoo and choose Restore Purchases. Purchases are tied to your Apple ID, so make sure you're signed in with the same account you bought with. If it still doesn't appear, get in touch.</p>

<h3>A file failed to convert</h3>
<p>AudioRoo accepts almost any container that holds audio, but some files are damaged or use unusual encodings. Mousing over the error indicator icon will provide you with a full error and reason for failure from the encoder. Include that output if you report it.</p>

<h2>Ask a Question</h2>
<p>Not sure whether something is a bug, or just want to ask how something works? Discussions is the place. Usage questions, compatibility concerns, and general feedback are all welcome.</p>
<p><a href="https://github.com/oddforms-design/AudioRoo/discussions">Open Discussions</a></p>

<h2>Report a Problem</h2>

<p>Bug reports go through this website, GitHub, which keeps everything in one place and lets you see whether someone has already hit the same thing.</p>

<p><a href="https://github.com/oddforms-design/AudioRoo/issues">Browse existing issues</a> &nbsp;|&nbsp; <a href="https://github.com/oddforms-design/AudioRoo/issues/new">Report a new bug</a></p>

<p>Helpful things to include:</p>
<ul>
  <li>Your macOS version and AudioRoo version</li>
  <li>What you did, what you expected, and what happened instead</li>
  <li>The file format you were converting from and to</li>
  <li>Screenshots or command monitor output, if relevant</li>
</ul>

<p>Issue reports are public, so please don't include anything private in filenames, screenshots, or logs.</p>
